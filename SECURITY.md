# Security Policy

## Supported versions

Zuzucord is currently in its initial planning stage. There are no released versions or security-supported builds.

## Reporting vulnerabilities

Please do **not** post security vulnerabilities, access tokens, credentials, or private user data in public GitHub issues.

If GitHub's private vulnerability reporting feature is enabled for this repository, use that feature. Otherwise, contact the repository maintainer through an appropriate private channel before disclosing details publicly.

## Security principles

- Never commit Discord user tokens, bot tokens, API keys, or secrets.
- Do not ask users to paste session tokens into the client.
- Use officially supported authentication and integration methods.
- Minimize collection and retention of personal data.
- Review dependencies and handle updates responsibly.

This policy will be expanded when a working client is available.
