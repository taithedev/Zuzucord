Developer operations

Only accounts with a server-granted developer role can publish or issue credits. Credits are promotional units, not money.

Official ZuzuCord announcement

Read-only message in the ZuzuCord announcements inbox. Rate-limited to one per 30 minutes. Users cannot reply to the official account.

◆ Grant Crystals

Crystals are ZuzuCord’s virtual community points. 100 Crystals = 1 server boost.

Developer-only; every grant is recorded in the recipient’s activity history. No purchases, transfers, or cash value.

Verified / beta badges

Developer role itself is granted only through a privileged administrator setup.

Bot HTTP API

Bots communicate with ZuzuCord through a server-side API. A server owner must install a bot by application ID before it can post in that server. The API checks the installation and throttles usage.

POST https://wfqudstuncdldsvxqveu.supabase.co/functions/v1/zuzucord-bot-api
Content-Type: application/json
X-ZuzuCord-Bot-Token: zcb_YOUR_SECRET_TOKEN

{"action":"send","channel_id":"CHANNEL_UUID","content":"Hello from my bot!"}

Maximum 1,500 characters, one message per three seconds, up to 200 per bot per UTC day. This token is NOT a Discord bot token.
