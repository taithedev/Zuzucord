PRIVACY INFORMATION

ZuzuCord privacy overview

This document describes the features currently implemented in the ZuzuCord website and Windows app. It is a project overview, not a substitute for an organization-specific legal privacy policy.

What we store

When you register, Supabase Auth handles your password and account credentials. The ZuzuCord database stores your username, account creation time, optional profile information, messages, and applicable moderation records. The website shows only aggregate totals for accounts, messages, and bans, not the identities behind those counts.

Username-only accounts

If you register without an email, ZuzuCord creates an internal login identifier for Supabase Auth. The public sign-in alias looks like username@zuzucord.com, but it is not a deliverable email address. Email-based password recovery is unavailable for these accounts, so keep your credentials safe.

Registration abuse prevention

The account registration service applies temporary request rate limits using a one-way fingerprint derived from network information. Registration attempts are tracked for abuse prevention.

Where to ask for help

For a security issue, see the project's security reporting instructions. Do not publish personal information or passwords in GitHub issues.
