Setup: Download the Windows installer from GitHub Releases. The installer adds ZuzuCord to Windows and supports repair and uninstall. Once installed, the application downloads newer verified updates automatically and applies them when you close or restart it. Portable ZIPs do not self-update.

Note: ZuzuCord is its own social application, not Discord. It does not connect to Discord user accounts.

GOOD TO KNOW

Questions.

Is ZuzuCord a Discord client?

No. ZuzuCord V2 is an independent community messaging application. It is not affiliated with Discord Inc.

Where do download counts come from?

GitHub's public Releases API. Downloads count published release assets, not all users, installations, or GitHub Actions artifacts.

Does the desktop app need internet?

Yes. Its account and messaging features connect to Supabase. The Windows client itself is written in C#.

Can I sign up without an email?

Yes. The username registration form creates an account that can be used in the Windows app. No email means no email-based password recovery. Existing ZuzifySocials email/password accounts can also sign in inside the app.
