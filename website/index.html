How to install: Use a published release asset when available. For a development build, open GitHub Actions, select a successful Windows build, and download its artifact (GitHub sign-in may be required). Extract the ZIP, then run ZuzuCord.exe.

Note: ZuzuCord is its own social application, not Discord. It does not connect to Discord user accounts.

GOOD TO KNOW

Questions.

Is ZuzuCord a Discord client?

No. ZuzuCord V2 is an independent community messaging application. It is not affiliated with Discord Inc.

Where do download counts come from?

GitHub's public Releases API. Downloads count published release assets, not all users, installations, or GitHub Actions artifacts.

Does the desktop app need internet?

Yes. Its account and messaging features connect to Supabase. The Windows client itself is written in C#.

Do I need to create another account?

ZuzuCord V2 connects to the same Supabase Auth project as ZuzifySocials. Existing email/password accounts can be used if enabled in Supabase Auth.
