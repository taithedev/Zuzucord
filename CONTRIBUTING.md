# Contributing to Zuzucord

Thanks for your interest in Zuzucord. The project is in its early stages, and thoughtful ideas and documentation improvements are welcome.

## Before contributing

- Check existing issues and discussions before opening a duplicate.
- Keep suggestions specific and explain the problem they solve.
- For larger changes, discuss the approach before implementing it.
- Respect Discord's terms, developer policies, and user privacy.

## Reporting bugs

Include a clear summary, steps to reproduce, expected behavior, actual behavior, and relevant environment details. Do not include passwords, tokens, private messages, or other sensitive data.

## Suggesting features

Describe the user need, the proposed behavior, and any accessibility or security implications.

## Pull requests

1. Create a focused branch.
2. Make one logical change per pull request where practical.
3. Explain what changed and how it was tested.
4. Update relevant documentation.
5. Be respectful in review discussions.

Coding conventions and automated test commands will be documented once the technology stack is selected.

## Community standards

Be constructive and respectful. Harassment, spam, and sharing private information are not acceptable.
